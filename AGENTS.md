# AGENTS

## Language Rules

- This project primarily serves Chinese-speaking users.
- Unless the user explicitly requests another language, all project documentation, analysis notes, presentation outlines, research summaries, and explanatory materials should be written mainly in Simplified Chinese.
- Keep technical product explanations beginner-friendly, practical, and easy to scan.
- When industry terms are clearer in English, keep the English term and provide a concise Chinese explanation when helpful.

## Content Direction

- Focus on popular AI applications, especially open source AI applications with strong real-world relevance.
- Analyze each application from the angles of operating principle, development scenario, short-term expectation, and daily-work integration.
- Output should support video scripts, basic research materials, structured data, and PPT content.

## Writing Style

- Prefer clear Chinese headings and structured sections.
- Avoid overly academic explanations unless necessary.
- Emphasize practical understanding: what it is, how it works, where it is useful, what can be built quickly, and how beginners can apply it.

## Repository Organization

- Prefer organizing content by app name first, not by content type first.
- Each analyzed AI application should have its own folder.
- Put that application's notes, data, PPT draft, and source links inside the same project folder whenever possible.
- Use type-based subfiles or subfolders only inside a specific project folder when the material grows.

## Exceptions

- Code, commands, file paths, config keys, API fields, and product names may remain in English.
- If a source quote or official term is better preserved in English, it may be kept as-is.
